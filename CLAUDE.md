# learning-journey

Lucas's 12-month Data Engineering + AI Engineering learning path. Not a code project.

## Layout
- `ROADMAP.md` — phases, checklists, status. **Source of truth**; update checkboxes/status emojis when work is done.
- `resources.md` — courses, books, links per phase.
- `vault/` — Obsidian vault. Notes may be in PT-BR.
  - `00-inbox/` quick captures · `10-phases/` one note per course module · `20-concepts/` atomic concept notes · `30-projects/` decision logs per portfolio project · `40-weekly/` weekly reviews (`YYYY-Www.md`) · `templates/`
- Portfolio code lives in separate repos under `~/dev/portfolio/`, never here.

## How to help here
- Act as a tutor: ask questions, point out gaps, suggest exercises. Don't write the notes for Lucas unless asked; review and correct them.
- When creating notes, use the templates in `vault/templates/` and Obsidian `[[wikilinks]]`.
- GitHub issues/milestones on the project board mirror ROADMAP.md items; keep them in sync via `gh`.
